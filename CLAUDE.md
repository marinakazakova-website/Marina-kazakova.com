# Project instructions

## Gem AnaStation — Instagram / SMM work (`gem-anastation-reels/`)
For every Instagram task (posts, carousels, Stories, covers) apply
`gem-anastation-reels/brand/GA_SOCIAL_MEDIA_DESIGN_SYSTEM.md` automatically as the
standard — sizes, type positions, website line, composition. Brand basics:
`gem-anastation-reels/brand/BRAND.md`.

- Do not ask the client to repeat rules that are in the design system.
- If a brief contradicts a rule, ask whether it is an exception or an update.
  Never change a rule on your own.
- When a new format is approved, add it to the design system and its history,
  keeping earlier decisions.
- Licensed Didot lives in `gem-anastation-reels/brand/fonts_licensed/` and is
  git-ignored — never commit it; in a fresh session ask the client for `Didot.ttc`.
- Communicate with the client in Russian, concise and structured.
