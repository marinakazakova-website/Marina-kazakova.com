# Founder's Note — closing slide template (1080 × 1350)

Rev. 4 (client): one editorial band across the full width — portrait 486 px
(45 %) and ivory text field 594 px (55 %) joined edge to edge, square
corners; navy #102537 above (0–221) and below (1054–1350, website line at
y = 1228 in #BBA375). Text field: 64 px inner margin, gold rule → Didot caps
74 px headline → AvantGarde 22 px letter → gold rule → Didot italic 42 px CTA
lead in deep teal #1A4043 → AvantGarde 21 px CTA line → signature at the
bottom of the field (ANASTASIA Didot 30 px #BBA375, role caps 13 px).
No logo, no arrow.

A new note = a new entry in `NOTES` in `tools/build.mjs`:
`NODE_PATH=$(npm root -g) node tools/build.mjs <id>`.
